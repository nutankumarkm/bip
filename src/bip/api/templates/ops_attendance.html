📊 How Data Flows Into This Feed

📡 ADMS Push (ZKTeco)
Device connects to BIP Edge on port 8001 and pushes attendance logs via HTTP. Punches appear here within milliseconds.
🔗 Gateway Agent
Edge gateway polls LAN devices and uploads batches to BIP. Works offline — syncs when connectivity is restored.
📥 File Import
Upload CSV, XLSX, or ZKTeco attlog.dat files via Import Sheet. Great for legacy backfill.
🔌 Webhook Delivery
Every punch here is simultaneously dispatched to your connected software via webhooks with HMAC signing.
