📦 Webhook payload format

BIP sends Content-Type: application/json with a BIP-Signature header. Verify it with your signing secret:

POST https://your-endpoint.example.com/bip-webhook Content-Type: application/json BIP-Signature: t=1729601234,v1=abc123... { "event": "punch.created", "timestamp": "2026-10-22T09:31:00Z", "punch": { "id": "pnc_abc123", "device_serial": "CDXZ202410001", "device_pin": "1042", "person_name": "Jane Smith", "punch_direction": "in", "verify_mode": "fp", "occurred_at": "2026-10-22T09:31:00Z" } }

Signature verification (Python)

import hmac, hashlib, time def verify_bip_signature(payload: bytes, header: str, secret: str) -> bool: parts = dict(p.split("=", 1) for p in header.split(",")) ts, sig = parts.get("t", ""), parts.get("v1", "") if abs(time.time() - int(ts)) > 300: # 5-min clock skew return False expected = hmac.new(secret.encode(), f"{ts}.".encode() + payload, hashlib.sha256).hexdigest() return hmac.compare_digest(expected, sig)

Signature verification (Node.js)

const crypto = require('crypto'); function verifyBipSignature(rawBody, header, secret) { const { t, v1 } = Object.fromEntries(header.split(',').map(p => p.split('='))); if (Math.abs(Date.now() / 1000 - Number(t)) > 300) return false; const expected = crypto.createHmac('sha256', secret).update(`${t}.${rawBody}`).digest('hex'); return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(v1)); }
